# Architectural Decision Records

Esta carpeta contendrá decisiones arquitectónicas duraderas una vez aprobadas.

Formato mínimo:

1. Título y estado.
2. Contexto y problema.
3. Alternativas relevantes.
4. Decisión.
5. Consecuencias.

Un ADR aceptado no se reescribe para ocultar su historia. Si cambia una decisión, otro ADR lo sustituye y enlaza el anterior.
